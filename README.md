# Sales-Prediction-using-Python
It is a Machine Learning project that predicts future sales based on historical sales data. It helps businesses plan inventory, estimate revenue, and understand sales trends.
1. Technologies used
- Python
- Pandas — data handling
- Matplotlib — data visualization
- Scikit-learn — machine learning
- Linear Regression — sales prediction model
2. Project workflow
  -> Historical Sales Dataset (CSV)
  ->Data Cleaning and Analysis
  ->Train Machine Learning Model
  ->Predict Sales
3. Python code for Sales Prediction
